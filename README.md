# スイムノート

GitHub Pagesの画面とGoogle Apps Scriptの保存APIを組み合わせた、スイミングスクールの名簿・進級テスト・練習メニュー管理です。データベースは非公開のGoogleスプレッドシートを使用します。

ルートの `index.html` が画面です。実際のGitHub Pagesへの配信対象は、同じHTMLを生成した `public/` だけに限定しています。名簿JSON・バックアップ・Excel・初期アカウント設定は公開対象に含めません。

## 初回の設定

詳しい手順は [GoogleとGitHubの設定手順](docs/SETUP.md) を参照してください。Google側のデプロイ後、`config.json` の `apiUrl` にウェブアプリの `/exec` URLを設定します。接続が未設定の場合は、ログイン画面に設定待ちと表示します。

## 機能

- 最後に合格した級とテスト日の満年齢から、次の受験級・種目・規定タイムを計算
- 任意の実測タイム、合格、クラス移動、退会、再入会の履歴
- 学年・生年月日を含むテスト名簿の印刷。100mには星と枠の目印
- 練習カードの作成・編集・削除、レッスンへの追加、並べ替え、予定時間の調整
- 合計時間・残り時間・距離・開始終了時刻のプレビューとメニュー印刷
- ID・パスワードでのログイン、10分無操作時の自動ログアウト
- 別PCからの更新を検出して上書きを防止。通信失敗時の保存再試行

## 開発

```sh
npm ci
npm run build
npm test
npm run check
```

`node tools/build.mjs` は依存パッケージなしで動きます。`index.html` と `public/index.html`、Apps Script用の計算モジュールを再生成します。暗号ライブラリは `backend/AuthCrypto.gs` に同梱済みです。元ライブラリのライセンスは `backend/NOBLE-LICENSE.txt` にあります。

既存のオフライン版と個人情報ファイルは、ローカルに残した旧フォルダで保管してください。既存名簿の移行には、旧アプリのバックアップJSONを新アプリの「データを開く」から反映します。

## 保存と認証の仕組み

画面のHTMLには、名簿やパスワード、パスワードの検証値を埋め込みません。ログイン情報はHTTPSのPOST本文でGoogle側へ送信し、サーバーでPBKDF2-HMAC-SHA256（60万回）の検証を行います。初期アカウントの検証値は非公開の `.local/InitialAccount.gs` に分け、Google側ではScript Propertiesに保持します。ログイン失敗が15分以内に5回続いた場合は待機が必要になります。

セッショントークンと取得した名簿は画面を開いている間のメモリだけに保持します。名簿とトークンをlocalStorage/sessionStorageには保存しません。通常の操作に応じてセッションを維持し、無操作で10分経過するとクライアント・サーバー双方で失効します。タブ終了・画面更新後は再ログインが必要です。タブ終了時の通知が届かなくてもサーバー側で期限切れになります。

Google Sheetsの `DB_A` / `DB_B` を交互に使用します。新しい内容を空いている側へ書き、検証が済んでから参照先を切り替えます。更新番号とロックで同時編集の上書きを防ぎます。これらのシートはアプリ管理専用で、直接編集せずアプリから操作してください。セルに表示するJSONには固定の接頭辞を付け、入力文字列を数式として実行させません。

Google APIの返答は非表示のiframeを経由したpostMessageで受け取ります。応答元のGoogleドメイン・送信元ウィンドウ・リクエストIDを確認し、返答先は設定済みのPagesオリジンに固定します。シートの公開設定やJSONPは使用しません。

## 検証範囲

計算・履歴・認証・保存競合・保存途中の失敗・自動ログアウト・練習メニューを自動テストしています。Googleサービスはテスト用実装、画面操作はDOM環境で検証しています。Googleへの初回デプロイ後に、実ブラウザでログイン・保存・別PCからの表示・印刷プレビューを確認してください。
